# AI Resume Analyzer

AI-powered Resume Analyzer and Resume Improvement platform built with Next.js, TypeScript, and Google Gemini AI.

---

## 🚀 Features

* 📄 Upload and analyze resumes
* 🎯 ATS-style resume analysis & scoring
* 🤖 AI-powered resume improvement suggestions
* 🧠 Optimize resumes based on job descriptions
* 💼 Generate tailored resumes for specific jobs
* 🎤 AI-generated interview questions based on resume & job role
* 📥 Export improved resumes as PDF
* ⚡ Real-time AI streaming responses

### 🤖 AI Features

* Google Gemini AI integration
* Real-time AI streaming responses
* Smart recommendations based on job descriptions
* AI-powered interview question generation
* Resume rewriting suggestions
* AI-enhanced ATS optimization

### 📤 Export & Sharing

* Export improved resumes as PDF
* Copy AI-generated suggestions instantly
* Download analysis reports

### 🎨 UI / UX

* Modern responsive design
* Dark / Light mode support
* Smooth animations with Framer Motion
* Mobile-friendly experience
* Skeleton loading states
* Toast notifications with Sonner

### ⚡ Performance & SEO

* Built with Next.js App Router
* Fast page loading
* SEO-friendly pages
* Optimized metadata & Open Graph support
* Server-side API routes
* Clean scalable architecture
